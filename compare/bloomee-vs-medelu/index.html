利用目的に応じてbloomeeとmedeluを選び分けられます

費用と手軽さを重視する場合はmedelu、ブランドの知名度やサービスの充実度を重視する場合はbloomeeをおすすめします。 それぞれに向いている方の特徴は以下のとおりです。

bloomeeが向いている方

  • --知名度の高いサービスを選びたい
  • --SNSで他の利用者の投稿を参考にしたい
  • --同封のガイドブックで飾り方を知りたい
  • --ギフトとしてお花の定期便を贈りたい

medeluが向いている方

  • --送料込みの実質負担をできるだけ抑えたい
  • --回数の条件なしで始めたい
  • --
  • --シンプルな料金体系を希望する
  • --まずは1回試してから続けるか決めたい

比較1：料金（送料込みの実質負担）

料金は、表示価格だけでなく送料を含めた1回あたりの実質負担額で比較することが重要です。

bloomee

お試しプラン

980円 + 送料385円 = 1,365円/回

ベーシックプラン

2,180円 + 送料550円 = 2,730円/回

グリーンプラン

980円 + 送料385円 = 1,365円/回

medelu

Miniコース

748円 送料無料 = 748円/回

1,330円 送料無料 = 1,330円/回

2,330円 送料無料 = 2,330円/回

料金比較のポイント

最安プラン同士で比較すると、medeluのLiteコース（748円）はbloomeeのお試しプラン（1,365円/送料込み）の約半額です。 medeluは送料込みの価格のため（北海道・東北へのLite以上は遠隔地送料140〜240円が加算（2026年10月17日公式確認））、表示価格がそのまま実質負担額になるシンプルな料金体系です。 bloomeeは花代とは別に送料385〜550円がかかるため、総額で考える必要があります。 隔週配送の場合、月額の差はbloomeeお試しプラン（月2,730円）とmedelu Miniコース（月1,496円）で約1,234円になります。

比較2：花の本数・ボリューム

bloomee

  • お試しプラン：4本以上（約18〜25cm）
  • グリーンプラン：グリーン中心
  • ベーシックプラン：8本以上（約25〜30cm）

medelu

  • Miniコース：3〜4本
  • Liteコース：5〜6本／Lite+コース：5〜7本
  • Basicコース：6〜9本

最安プラン同士では、medelu Mini（3〜4本）とbloomeeお試し（4本以上）で本数に大きな差はありません。 中間プランでは、medeluのLiteコース（5〜6本/1,330円・送料込み）がbloomeeのベーシックプラン（8本以上/2,730円・送料込み）より1回あたり約1,400円安く、本数はbloomeeのベーシックが多くなっています。 1本あたりの単価では、medeluの費用対効果が高い水準にあります。

比較3：配送方法

bloomee

  • お試し・グリーン：ポスト投函
  • ベーシックプラン：宅配便
  • ポスト投函はゆうパケットを利用
  • 専用の縦長パッケージで届く

medelu

  • Mini・Lite：ポスト投函
  • Lite+・Basic：宅配便
  • ポスト投函は日本郵便を利用
  • 専用パッケージで届く

配送方法はどちらもほぼ同じ仕組みです。低価格プランはポスト投函、上位プランは宅配便（手渡し）になります。 ポスト投函は不在時でも受け取れるため、一人暮らしの方や日中不在の方にとって便利です。 どちらのサービスも、ポストの投函口が幅4.5cm以上・奥行き15cm以上あれば問題なく届きます。

比較4：配送頻度の選択肢

bloomee

  • 毎週 / 隔週から選択
  • マイページからいつでも変更可
  • スキップ機能あり（無料）

medelu

  • 隔週 / 毎週から選択
  • マイページからいつでも変更可
  • スキップ機能あり（無料）

配送頻度の選択肢はどちらも同じで、毎週または隔週から選べます。 どちらもマイページから配送頻度の変更が可能で、旅行や出張で受け取れない週は、スキップ機能で配送を休止できます。 スキップは無料のため、生活に合わせて柔軟に調整できます。この項目では両者に差はありません。

比較5：解約のしやすさ

解約のしやすさは、両サービスで大きく異なるポイントです。特に、まず試してみたい方にとって重要な比較基準です。

bloomee

4回の最低受け取り回数あり

  • 4回未満の解約は残り回数分が違約金として発生
  • マイページから解約手続き可能
  • 解約ページまでに複数ステップあり
  • 引き止めページが表示される

medelu

回数の条件なし・いつでも解約可能

  • 初回から解約自由
  • マイページから簡単に解約可能
  • 違約金・手数料なし
  • 解約手続きがシンプル

解約のしやすさの評価

解約のしやすさではmedeluが有利です。medeluは回数の条件も違約金もなく、いつでもマイページから解約できます。 bloomeeは4回の最低受け取りが条件で、お試しプランの場合は最低でも5,460円（1,365円×4回）の利用が確定します。 まず1回試してから判断したい方には、金銭的な負担が少ないmedeluをおすすめします。

比較6：花の鮮度

bloomee

  • 口コミでは「しおれていた・同じ花が続く」という声が目立つ
  • 定期便は2週間以内の連絡で返金・交換（特商法）
  • 夏場のポスト投函は傷みのリスクがやや高い

medelu

  • 生産者と市場から直接仕入れた花を届けると案内（2026年10月21日公式確認）
  • 品質保証制度あり

bloomeeは、市場で仕入れた花を束ねて届けると案内しています（2026年10月20日公式確認）。 なお品質保証は、bloomeeが定期便なら2週間以内の連絡で返金・交換、medeluは到着当日中の写真送付で全額返金（交換なし）と条件が異なります。

比較7：マイページでの手続きと同封物

bloomee

  • マイページで特定の週のスキップが可能
  • 4回目の受け取り後は、マイページで隔週に変更可能
  • プランの変更・切り替えもマイページから
  • お花のガイドブックが付き、栄養剤が毎回同封される
  • お届け先の入力画面で「プレゼントとして送る」を選べる

medelu

  • Webのマイページで管理
  • マイページでプラン変更・スキップが可能
  • 花の情報はメールで届く
  • シンプルなサービス設計

どちらも、スキップやプランの変更はWebのマイページで行います。bloomeeは、4回目の受け取り後に隔週への変更ができ、お花のガイドブックが付き、栄養剤が毎回同封されます（2026年10月21日公式確認）。 また、お届け先の入力画面で「プレゼントとして送る」を選べるため、プレゼントにも利用できます。 当サイトでは、bloomeeの専用アプリを公式サイトとApp Storeで確認できませんでした（2026年10月21日時点）。

比較8：ブランド認知度・実績

bloomee

  • 2016年サービス開始
  • 累計3,000万本以上のお花をお届け
  • SNS投稿数が花のサブスクで最多クラス
  • テレビ・雑誌等のメディア掲載多数
  • 花のサブスクの代表的なサービスとして知られる

medelu

  • 2018年サービス開始
  • 価格の手頃さが口コミで広がっている
  • SNS投稿数はbloomeeと比べると少なめ
  • 花のサブスク比較サイトで高評価が多い
  • 認知度に比べてサービス内容の評価が高い

ブランド認知度ではbloomeeが大きく上回っています。2016年の早期参入で花のサブスク市場を開拓し、SNSやメディアでの露出も多いため「花のサブスク＝bloomee」というイメージが定着しています。 一方、medeluは2018年開始の後発サービスですが、価格の手頃さが口コミで広がり、比較検討する層からの支持を集めています。 利用者の多さによる安心感を重視する場合はbloomee、実質的なサービス内容を重視する場合はmedeluが適しています。

利用シーン別のおすすめ

当サイトでは、利用シーンごとにbloomeeとmedeluのどちらが適しているかをご説明します。

一人暮らしの場合medeluがおすすめ

一人暮らしで花のサブスクを始める場合は、medeluをおすすめします。送料無料で748円から始められるため月々の負担が少なく、回数の条件がないため、生活に合わない場合はすぐに解約できます。ポスト投函で受け取れるため、不在が多い一人暮らしの方にも適しています。

プレゼントとして贈る場合bloomeeがおすすめ

bloomeeは、お届け先住所の入力画面で「プレゼントとして送る」を選ぶと、相手の住所に届けられ、送り主の名前を登録できます（2026年10月20日公式確認）。medeluのギフトでの申し込み方法は、公式サイトでご確認ください。

費用を重視する場合medeluがおすすめ

費用対効果を最も重視する場合は、medeluをおすすめします。送料込みの実質負担額はbloomeeの約半額で、回数の条件もないため不要な出費が発生しません。Liteコース（1,330円）でも5〜6本届くため、同価格帯のbloomeeお試しプラン（1,365円/4本以上）よりボリュームがあります。

初めての利用で不安がある場合bloomeeがおすすめ

花のサブスクが初めてで不安がある方には、bloomeeが向いています。お花のガイドブックが付き、栄養剤も毎回同封されるため、初めての方でも飾り方を確認できます（2026年10月21日公式確認）。SNSに利用者の投稿が多いため、事前にどんな花が届くか参考にできる安心感もあります。ただし、最低4回の受け取り条件がある点にご注意ください。

bloomee vs medeluに関するよくある質問

bloomeeとmedeluの選び方のまとめ

bloomeeとmedeluは、重視する点によって適したサービスが異なります。

費用と手軽さを重視する場合はmedeluが適しています。送料無料で748円から始められ、回数の条件もないため、金銭的な負担を抑えて試すことができます。 花のある生活を手軽に始めたい方に向いています。

ブランドの知名度やサービスの充実度を重視する場合はbloomeeをおすすめします。「プレゼントとして送る」での申し込みや、お花のガイドブックなど、初めての方向けの案内があり、SNSでの情報量も豊富です。 花のサブスクの代表的なサービスとしての安心感があり、プレゼント用途にも対応しています。
