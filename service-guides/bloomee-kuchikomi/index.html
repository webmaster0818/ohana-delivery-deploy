bloomee (ブルーミー) の 口コミ・評判

bloomee(ブルーミー)の値段・料金プランと口コミ・評判｜4回縛りの実態

bloomee(ブルーミー)は提携花屋から季節の花が届く老舗の花サブスクです。本ページでは、SNS・レビューサイトで繰り返し見られる評価の傾向を良し悪し両面から整理し、あわせて2026年6月12日に公式サイトで確認した料金・継続ルール・配送方式の一次情報を掲載します。個人の感想は人により異なるため、傾向と公式事実を分けて記載しています。

bloomee(ブルーミー)の値段・料金プラン(公式確認 2026年7月3日)

■お試しプラン: 花代980円＋送料385円/回 = 実質1,365円/回(3本以上・ポスト投函) ■ベーシックプラン: 花代2,180円＋送料550円/回 = 実質2,730円/回(手渡し配送・日時指定可) ■最低継続: 最初の4回。お試しプランなら4回総額の目安は約5,460円 ■4回未満の解約は残回数分の途中解約料が発生(特商法ページに明記) ※価格・条件は変わるため最新は公式サイトでご確認ください。『980円』は花代のみの表記で、送料を含めた実質金額で比較するのがポイントです。

結論: bloomee の評判の全体傾向

良い評価で多いのは『ポスト投函で受取が楽』『980円〜で始めやすい』『提携花屋ごとの個性が楽しい』の3点。不満で多いのは『最初の4回継続が必須』『花の種類を選べない』『提携花屋によって品質に差がある』の3点。手軽さ重視の長期利用者ほど満足度が高く、1〜2回だけ試したい人とのミスマッチが不満の中心です。

公式サイトで確認した基本情報 (2026年6月12日時点)

■料金: 市場で仕入れた季節の花が980円〜(プランにより異なる) ■最低継続: あり。公式に『最初の4回分のお届けをお約束』と明記 ■スキップ: 特定の週のみお届けを飛ばせる機能あり。4回目の受取後は隔週お届けへの変更も可能 ■配送: お試しプランはポスト投函(水〜金曜・日時指定不可)、ベーシックプランは手渡し配送(水〜日曜・日時指定可、一部エリアは宅配便) ※最新の条件は必ず公式サイトでご確認ください。

良い評判の傾向

①受取の手軽さ: ポスト投函のため不在でも受け取れる点は、共働き・一人暮らし層から一貫して高評価。②価格の入りやすさ: 980円〜という価格は花サブスク全体でも低い水準で、『花のある生活』の入門として選ばれやすい。③提携花屋の個性: 全国の提携花屋から発送される仕組みのため、定型ブーケにない組み合わせが届くことを楽しむ声が多い。

不満の傾向と『4回縛り』の正確な条件

不満で最も多いのが最低4回の継続ルールです。公式サイトに『最初の4回分のお届けをお約束』と明記されており、4回受取前の解約には所定の支払いが生じる設計です(詳細条件は公式の利用規約を要確認)。次に多いのが『花の種類を選べない』『花屋により品質・ボリュームに差がある』という声。ポスト投函は夏場の高温の影響を受けやすい点も指摘されます。これらは仕組み上のトレードオフのため、契約前に把握しておくと失敗が減ります。

向く人・向かない人

【向く人】4回以上続ける前提で花のある生活を試したい/受取の手間を最小にしたい/届く花はお任せで楽しめる。【向かない人】1〜2回だけ試したい(回数縛りなしのタスハナ・medeluが向く)/花の種類を自分で選びたい/品質の均一性を最優先したい。

運営会社の事実確認（2026年7月3日）

運営はユーザーライク株式会社（東京都渋谷区道玄坂・旧社名Crunch Style）。国税庁法人番号公表サイトで実在・所在地一致を確認済み（法人番号7012401025849）。公式公表の実績は「お花のお届け実績3,000万本以上（自社調べ）」で、農林水産大臣賞・日本スタートアップ大賞2022の受賞記載もあります。料金はお試し980円＋送料385円/回、ベーシック2,180円＋送料550円/回（税込・2026年7月3日公式確認）。

よくある質問

Qbloomee は結局おすすめできる？
4回以上続ける前提なら、価格と受取の手軽さで有力候補です。1〜2回のお試し目的なら、回数縛りのないタスハナや medelu のほうがミスマッチがありません。
Q悪い口コミで一番多い不満は？
『最初の4回継続が必須』である点です。次いで『花の種類が選べない』『提携花屋による品質差』が続きます。
Q4回縛りの途中で解約するとどうなる？
公式が『最初の4回分のお届けをお約束』と明記しているため、4回未満での解約には所定の支払いが生じる設計です。正確な金額・条件は申込前に公式の利用規約をご確認ください。
Qbloomee と medelu はどちらが良い？
bloomee は低価格とポスト投函の手軽さ、medelu は回数縛りなしの辞めやすさが強みです。お試し重視なら medelu、続ける前提の手軽さなら bloomee が向きます。
Q配送日時は指定できる？
お試しプランはポスト投函で日時指定不可(水〜金曜のお届け)。ベーシックプランは手渡し配送で日時指定が可能です(水〜日曜、一部エリアは宅配便)。2026年6月12日に公式サイトで確認した情報です。
